# Contributing

Thank you for contributing to this project.

## Local Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

## Branching

- Create small, focused branches from `main`.
- Keep branch scope limited to one clear change.

## Pull Requests

- Open pull requests instead of pushing directly to `main`.
- Before opening a pull request, run:
  ```bash
  npm run lint
  npm run typecheck
  npm run build
  ```

## Commits

- Keep commits focused and small.
- Prefer single-purpose commits with clear messages.
