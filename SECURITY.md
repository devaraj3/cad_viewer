# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, report vulnerabilities privately by emailing `security@example.com`.

Include the following details when possible:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Any suggested mitigation

## Response Timeline

We will acknowledge new reports within 5 business days and provide status updates as the investigation progresses.
